# Broom (2022)

Broom is a Doom-inspired first-person shooter where players take on the role of a janitor fighting aliens using mops and other cleaning supplies as weapons.

The game was developed in 2022 as a **group project for a Game Development course at the University of Texas at San Antonio (UTSA)**.

This repository contains the project files from our university coursework.

## Download and Play

The game is available to download on itch.io:

**[Broom — itch.io](https://sebastianklemkosky.itch.io/broom)**
